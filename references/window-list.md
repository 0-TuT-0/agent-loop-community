# 开窗清单

总控每次输出进展或票列表时，都在回复末尾附上开窗清单。内容来自 `scripts/loop-state.sh` 的输出（与选票用的是同一份就绪判定），再加上总控的判断。

完成标准：每张非终态票恰好出现一次；被阻塞的票写明在等什么。

```markdown
### 进行中
- **<ID> <票名>**：<Run>（<Run-id>，<角色>），<引擎>/<模型>，开始于 <时间>，期限 <时间>

### 等裁决
- **<ID>**：待裁决 <n> —— <一句话问题> —— <总控已裁 / 等用户>

### 下一批（总控将自动派工）
- **<ID> <票名>**：风险 <级别> → <角色>，<引擎>/<模型>

### 被阻塞
- **<ID>**：<loop-state.sh 的 reason，翻译成一句话>，例如「等 03 验收」「依赖 x9 不存在」「等用户执行 a.sql（X1）」

### 已暂停（paused）
- **<ID>**：<原因>，<需要用户决定什么>

### 需要用户做的事
- <事项>：<原因；做完后哪些票可以继续>
```

某一节没有内容时，省略这一节。
